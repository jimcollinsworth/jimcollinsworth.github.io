# Release v0.6.3 — Responsive Image Containment & Edge-to-Edge Photo Stream

> Fixed unconstrained full-resolution post images from blowing out viewports, enforced global fluid image containment (\max-width: 100%\), added editorial \<figure>\ and \<figcaption>\ styling, enabled edge-to-edge zero-gutter display for photo albums on portable devices, and added Playwright automated image containment audits.

---

### Overview

\0.6.3\ resolves a layout blowout where high-resolution images embedded in posts (such as 2,108px wide architectural photography in \rt-institute-chicago-modern-wing.md\) rendered at intrinsic dimensions without bounds, causing severe horizontal overflow on mobile, tablet, and laptop displays. This release institutes universal fluid media constraints, styles editorial \<figure>\ / \<figcaption>\ elements, and enables immersive edge-to-edge photo album rendering on mobile and tablet screens.

---

### Key Changes & Upgrades

1. **Fluid Responsive Media Containment (\style.css\)**:
   - Added global media reset: \img, picture, video, canvas { max-width: 100%; height: auto; }\ preventing any media asset from overflowing its container or viewport.
   - Standardized editorial \<figure>\ and \<figcaption>\ styling across all markdown articles and essays, with subtle borders, graceful border radiuses, and readable typography.

2. **Edge-to-Edge Photo Stream for Albums (\photos.html\)**:
   - Implemented edge-to-edge zero-gutter photo styling for \.photo-stream\ on mobile (< 640px) and tablet (< 1024px) viewports (\margin-left: -1rem; margin-right: -1rem; width: calc(100% + 2rem)\).
   - Preserves caption padding so captions maintain clean alignment with page titles and navigation.

3. **Automated Visual Regression Audits (\	est_playwright_responsive.py\)**:
   - Added \	est_images_fit_viewport_width\ parameterized across phone and laptop viewports.
   - Verifies \document.documentElement.scrollWidth <= clientWidth\ (zero horizontal overflow) and checks each individual \img\ bounding box against the active viewport width.

4. **Synchronized Theme & Distribution CSS**:
   - Kept \ssets/css/style.css\, \	heme/static/css/style.css\, and \	heme/css/style.css\ fully identical.
