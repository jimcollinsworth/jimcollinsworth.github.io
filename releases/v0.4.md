# Release v0.4 — Deployment Synchronization & Custom JC Favicon

> Resolved GitHub Pages branch serving mismatches, integrated .nojekyll bypass, and introduced the custom "JC" monogram favicon.

---

### Overview

`v0.4` addressed deployment discrepancies between Pelican's compiled `output/` and GitHub Pages branch serving. It introduced root synchronization routines, bypassed Jekyll processing, and replaced default icons with a custom vector "JC" favicon.

---

### Key Features & Changes

- **GitHub Pages Branch Synchronization**: Synchronized repository root HTML with Pelican's output so deployments from `main` branch root serve identical templates.
- **Jekyll Bypass (`.nojekyll`)**: Added `.nojekyll` metadata rule to prevent GitHub Pages from ignoring folders or reprocessing CSS.
- **Custom "JC" Monogram Favicon**:
  - Vector `favicon.svg` with built-in `@media (prefers-color-scheme: dark)` color-switching (rust in light mode, amber in dark mode).
  - Multi-resolution `favicon.ico` (16px to 64px) for legacy browser fallback.
- **Hardened Test Verification**: Expanded `test_pelican_e2e.py` to assert zero pills and clean title deduplication across both `output/` and root HTML files.
