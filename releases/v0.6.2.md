# Release v0.6.2 — 'Me' Category, Configurable Menu System & Downlow Iconography

> Added `Me` as an autobiographical and biodata category, renamed `AI Generated` to `AI`, kept categories "on the downlow" across public navigation while documenting them on `about.md`, introduced subtle inline category icons next to posts, established a configurable menu architecture, and resolved artifact screenshot preview rendering.

---

### Overview

`v0.6.2` refines content categorization and site navigation based on Jim's directives. It expands the provenance taxonomy to 5 distinct streams (`Me`, `Mine`, `AI`, `Ours`, `Theirs`), removes visible category filter bars to maintain distraction-free reading, and introduces subtle, accessible category icons in post metadata. Furthermore, the top navigation menu is now fully configurable via Pelican's `MENUITEMS` setting while also allowing any Markdown page to opt in dynamically via `menu: true` frontmatter.

---

### Key Changes & Upgrades

1. **Category Taxonomy Refinement (`Me`, `Mine`, `AI`, `Ours`, `Theirs`)**:
   - Added **`Me`**: Direct autobiographical notes, personal biodata (Fitbit/activity, sleep, health tracking), personal bookmarks, and reflections about Jim written by Jim.
   - Renamed **`AI Generated`** &rarr; **`AI`** for clean, succinct naming.
   - Preserved **`Mine`** (Jim's original writing & making), **`Ours`** (collaborative works), and **`Theirs`** (curated external references and quotes).

2. **Downlow Category Presentation & Subtle Iconography**:
   - Retired visible category navigation bars (`All • Mine • Ours`) from `posts.html` and `category/*.html`.
   - Removed `STREAMS: Mine • Ours` from the site footer.
   - Added a dedicated "Content Streams & Categorization" explanation on [`about.md`](about.html) to quietly establish the taxonomy.
   - Introduced subtle 13×13px inline SVG category icons next to posts in archives, index feeds, and article headers:
     - `Me`: `👤` Minimalist user silhouette outline
     - `Mine`: `🖋️` Minimalist fountain pen nib outline
     - `AI`: `✦` Minimalist four-pointed sparkle
     - `Ours`: `👥` Minimalist collaborative users outline
     - `Theirs`: `❝` Minimalist quotation mark outline
   - Screen-reader accessible via `aria-label="Category: <name>"` and browser `<title>` tooltips.

3. **Configurable Navigation Menu**:
   - Permanent core pages: **`Home`**, **`About`**, and **`Posts`** (or Blog).
   - Configurable site items via `MENUITEMS` in `pelicanconf.py` (`AI`, `Links`, `Photos`, `Apps`, `Site`).
   - Page frontmatter opt-in: Any new Markdown page in `content/pages/` (such as `tai-chi.md` or `music.md`) can declare `menu: true` (and optional `menu_order: 5`) to automatically be placed on the navigation bar.

4. **Screenshot Tooling & Preview Diagnostics**:
   - Resolved walkthrough artifact image previews by standardizing image URIs to `file:///C:/Users/...` (eliminating Windows backslash escape issues).
   - Verified multi-viewport screenshot generation and Playwright browser testing.

5. **Testing & Governance**:
   - Updated test suites (`tests/test_accessibility.py` and `tests/test_playwright_responsive.py`) with all tests passing.
   - Synchronized `AGENTS.md`, `.agents/agent_rules.md`, `PLANNING.md`, `JOURNAL.md`, and `pyproject.toml`.
