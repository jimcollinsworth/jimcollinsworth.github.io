# Release v0.5.7 — Contact Page, Footer Links, Section Taxonomy & UI Visual Protocol

> Added dedicated Contact page, refined footer navigation, reorganized section taxonomy (Shelf, Photos, Events), streamlined 2-line header layout, and codified the visual evidence protocol in agent governance.

---

### Overview

`v0.5.7` delivers key structural, navigation, and governance updates: creating a zero-JS Contact page, refining footer links with primary secondary pages, updating content section taxonomy across the site, perfecting the two-row responsive header and high-contrast layout, and establishing the mandatory visual screenshot protocol for agent-assisted UI walkthroughs.

---

### Key Features & Additions

- **New Zero-JS Contact Page (`contact.html`)**:
  - Clean editorial contact page with direct `mailto:` link, guidance on topics of mutual interest (classical guitar, software, health, Chicago skies), and site privacy stance.
- **Deduplicated & Enhanced Footer Navigation (`base.html`)**:
  - Removed duplicate header links from the footer.
  - Added direct secondary navigation: `About Site`, `Dev Prompts`, `Contact`, and `Google Photos`.
- **Section Taxonomy Refinements**:
  - Renamed **Reads** &rarr; **Shelf** (`shelf.html`).
  - Renamed **Gallery** &rarr; **Photos** (`photos.html`).
  - Renamed **Views** &rarr; **Events** (`events.html`).
  - Updated homepage "From the Shelf" spotlight and internal cross-references.
- **2-Line Header Layout & Compact Controls**:
  - Row 1: Brand title on far left, tagline "Out of My Lane" right-aligned.
  - Row 2: Navigation menu on left, compact 28x28px borderless toggles on right.
  - Eliminated bulky card boxes around theme and accessibility icons.
- **High-Contrast View Optimization**:
  - Maintained 2-line header layout horizontally without column breaks or `[Active Page]` wrapping.
  - Tightened typography line-height from 1.85 to 1.55 for comfortable vertical rhythm.
- **Agent Governance & UI Visual Evidence Protocol**:
  - Codified **Section 13 (Visual Evidence & UI Walkthrough Protocol)** into `AGENTS.md` and `.agents/agent_rules.md`: mandatory inline screenshots in reports before push or merge approvals.
- **Testing & Verification**:
  - Comprehensive 42/42 automated test suite passing (`pytest`).
