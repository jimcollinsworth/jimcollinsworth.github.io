# Release v0.7.2 — Post Header Consolidation, Framed App Mockups & Full-Screen Photos

> Consolidated post headers to a single compact row, added framed app screenshot mockups with top launch buttons, enabled full-screen photo viewing, removed copyright footer, and unbolded post types.

---

### Key Changes

1. **Apps Hub & Post Linking**:
   - Card titles link directly to dedicated app posts; removed redundant button links.
   - Decommissioned legacy embedded page `pipeline-tools.md`.

2. **Consolidated Post Header**:
   - Consolidated inline back arrow (`?`), provenance badge, title, and right-aligned unbolded `Type Date` into a single line.
   - Eliminated standalone back link row.

3. **App Post Layout & Framed Mockups**:
   - Primary `Launch Full-Screen App ?` button placed immediately following intro paragraph.
   - Framed 640px screenshot inside `.screenshot-frame` with accent border and rounded corners.

4. **Full-Screen Photo Viewing**:
   - Wrapped images with `a.photo-link` and `cursor: zoom-in` across gallery, spotlight, and posts.

5. **Footer & Section Spacing**:
   - Removed bottom copyright notice line.
   - Tightened section spacing and unbolded post types across listings.
