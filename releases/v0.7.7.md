# Release v0.7.7 — Homepage Layout: Photo Spotlight Reordered After Featured Post

**Release Date:** September 14, 2026  
**Commit:** Milestone 42  
**Tag:** `v0.7.7`

---

### Overview

Release `v0.7.7` refactors the homepage magazine grid layout (`theme/templates/index.html`). The **Photo Spotlight** section has been relocated from the sidebar column into the primary reading column, positioned directly after the **Featured Post** and before **Recent Links**.

---

### Key Changes

1. **Homepage Template Layout (`theme/templates/index.html`)**:
   - Relocated `Photo Spotlight` from `.sidebar-column` into `.main-column` immediately following `Featured Post`.
   - Removed the preceding `<hr>` separator from `.sidebar-column`.
   - Balanced vertical column heights in desktop two-column grid: left column pairs Featured Post, Photo Spotlight, and Recent Links; right column displays Recent Stream.
   - Preserved single-column mobile reading progression: Welcome Intro &rarr; Featured Post &rarr; Photo Spotlight &rarr; Recent Links &rarr; Recent Stream.

2. **Automated Testing & Build Integrity**:
   - Rebuilt static site via Pelican (`0.13s`).
   - Verified 52/52 passing automated tests in `pytest -v` across accessibility, Pelican compilation, responsive viewports, and zero-JS invariants.
