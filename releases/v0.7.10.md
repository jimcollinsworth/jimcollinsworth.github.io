# Release v0.7.10 — Chat Bubbles, AI Summary Generator, Mobile Header Streamlining & Timestamp Precision

**Release Date:** September 15, 2026  
**Commit:** Milestone 47  
**Tag:** `v0.7.10`

---

### Overview

Release `v0.7.10` enhances conversational prompt history styling with chat bubbles and exact timestamps, adds an automated 8-stanza AI haiku summary generator for site milestones, modernizes dashboard panels with compact action buttons, simplifies mobile headers by moving site controls to the footer, and normalizes featured post typography on the home page.

---

### Key Changes

1. **Conversational Chat Bubbles (	heme/static/css/style.css, 	ools/sync_dev_prompts.py)**:
   - Upgraded `content/pages/prompt-history.md` generator to emit structured chat threads (.chat-thread).
   - Jim's steering prompts are rendered in .chat-user bubbles with warm accent left borders and exact commit timestamps.
   - AI assistant actions are rendered in .chat-ai bubbles with subtle card backgrounds and explicit author attribution (LLM-Gemini3.8).

2. **Automated Site History AI Summary (	ools/generate_site_summary.py, content/data/site-summary.json)**:
   - Created build utility generate_site_summary.py that parses JOURNAL.md and generates an 8-stanza thematic summary.
   - Integrated SITE_SUMMARY context into pelicanconf.py and rendered Summary (written by AI) on bout-this-site.html.

3. **Mobile Header Simplification & Footer Controls Relocation (	heme/templates/base.html, 	heme/static/css/style.css)**:
   - Relocated .site-controls (theme mode, contrast, font sizing) from top header to .site-footer.
   - Scaled down mobile site title typography and streamlined phone portrait navigation to show only the active item.
   - Expanded .footer-nav with comprehensive direct links to all site pages.

4. **Dashboard Modernization & Exact Release Timestamps (	heme/templates/about-this-site.html, pelicanconf.py)**:
   - Replaced trailing action links with .btn-compact modern buttons on .dashboard-card elements.
   - Added RECENT_RELEASES table displaying recent milestones with exact commit dates and times (e.g., Sept 14 2026, 3:33 PM CDT).

5. **Home Page Featured Post Typography Normalization (	heme/templates/index.html, 	heme/static/css/style.css)**:
   - Normalized .post-item.featured title font size to 1.05rem and weight to 600, harmonizing visual hierarchy with sidebar post items.
   - Standardized teaser container to <p class="post-teaser">.
