# Release v0.6.7 — Header Horizon Bar, Reversed Active Nav & Obsidian Post Template

> Added an architectural 4px basic grey horizon bar below the header, updated active navigation items to a high-contrast reversed pill with zero clashing underlines, and added an official, comprehensive Obsidian post template to the repository.

---

### Overview

v0.6.7 delivers key visual refinement and content authoring improvements:

1. **Header Horizon Bar**:
   - Added a grounded 4px basic grey horizontal bar below `header.site-header` on desktop (`--border-header: #b5b0a6` in light mode, `#44494e` in dark mode).
   - Scaled to 3px on mobile screens (< 640px) and phone landscape (< 500px height) to maintain tight vertical rhythm.

2. **Reversed Active Navigation Pill**:
   - Replaced the bottom border underline on `nav.site-nav a` with a reversed high-contrast pill (`background-color: var(--text); color: var(--bg) !important; font-weight: 600; border-radius: 4px; padding: 0.25rem 0.65rem; border-bottom: none;`).
   - Eliminated `border-bottom` on all navigation links, preventing any visual clash with the horizontal header bar below and eliminating hover jitter.
   - Symmetrically inverts in light mode (charcoal pill / cream text) and dark mode (cream pill / dark charcoal text).
   - Mirrored the reversed pill styling on active items in the mobile dynamic dropdown menu.
   - Maintained full WCAG 2.1 AAA touch target compliance (`min-height: 38px`).

3. **Obsidian Post Template (`templates/obsidian-post-template.md`)**:
   - Created an official Obsidian post template at the repository root.
   - Fully documents all 7 frontmatter sections with detailed explanations and allowed values:
     - Core metadata (`title`, `date`, `slug`)
     - Provenance streams (`category`: `Mine`, `Me`, `AI`, `Ours`, `Theirs`)
     - Content formats & lifecycles (`type`: `NOTE`, `ESSAY`, `PROJ`, `VIEW`, `BOOK`, `TIL`, `SPEC`, `IDEA`, `WIP`, plus `previous_types: [...]`)
     - Topic tags (`tags: [...]`)
     - Publishing states (`status`: `published`, `draft`, `hidden`)
     - Summary teaser, hero media, and page menu configurations
   - Includes a starter editorial Markdown skeleton (lede paragraph, semantic `<figure>`/`<figcaption>`, callouts, code blocks, lists).
