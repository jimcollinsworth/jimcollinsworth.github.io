# Release v0.6.5 — Dynamic Mobile Dropdown Menu in Portrait Mode (Zero-JS)

> Implemented a dynamic hiding dropdown menu in mobile portrait mode that displays the active page name with a dropdown indicator (`[ Current Page ▾ ]`) on a strictly single-row header, expanding into a floating navigation card on tap using 100% pure HTML5 `<details>` and `<summary>` without a single line of JavaScript.

---

### Overview

`v0.6.5` fulfills Jim's requirement for a dynamic hiding dropdown navigation in mobile portrait mode. Previously, on narrow phone screens in portrait orientation, displaying 8 separate navigation links caused the header to wrap across 3–4 vertical rows.

With this release:
- **Portrait Mobile (< 640px)**: The entire header is flattened to a **single row** (~40px height). It displays `Jim Collinsworth` on the left, an interactive button showing the current active page with a chevron (`[ Home ▾ ]`, `[ Posts ▾ ]`, `[ About ▾ ]`, `[ Site ▾ ]`, etc.) and the theme switchers (`🌙 ◑ A`) on the right. Tapping the button opens a clean floating navigation card with large touch targets and active page highlighting.
- **Landscape Phone (< 500px height)**: Preserves the full horizontal navigation bar (`Jim Collinsworth` | `Home About Posts AI Links Photos Apps Site` | `🌙 ◑ A`) on a single line as introduced in `v0.6.4`.
- **Desktop (> 640px)**: Preserves the standard editorial navigation bar.
- **Zero JavaScript**: 100% compliant with Rule 3 using native semantic HTML5 `<details>` and `<summary>` disclosure widgets.

---

### Key Changes & Upgrades

1. **Semantic HTML5 `<details>` & `<summary>` Mobile Dropdown**:
   - Added `<details class="mobile-nav-dropdown">` and `<summary class="mobile-nav-summary">` to `theme/templates/base.html`.
   - Utilizes Jinja2 `namespace` logic to automatically detect and display the active page title on the closed button (`Home`, `About`, `Posts`, `AI`, `Links`, `Photos`, `Apps`, `Site`, or `Menu`).
   - SVG chevron indicator automatically rotates 180 degrees when opened via CSS transition (`transform: rotate(180deg)`).

2. **Single-Row Portrait Header Layout**:
   - Switched mobile `header.site-header` to a clean flex row layout (`justify-content: space-between; align-items: center;`).
   - Sits `Jim Collinsworth` on the far left, and groups `[ Current Page ▾ ]` alongside `🌙 ◑ A` on the right.
   - Fits comfortably on screens as narrow as 320px with zero wrapping.

3. **Floating Card Menu Styling**:
   - Positioned `.mobile-nav-menu` as a floating card beneath the dropdown button (`position: absolute; right: 0;`).
   - Styled with `var(--bg-card)`, subtle border `var(--border)`, and soft drop shadow (`box-shadow: 0 6px 20px rgba(0, 0, 0, 0.14)`).
   - Touch targets meet WCAG 2.1 AAA accessibility requirements with `min-height: 38px`.
   - Fully styled across light mode, dark mode (`prefers-color-scheme: dark`), and high-contrast low-complexity mode (`#contrast-toggle:checked`).

4. **Automated Verification**:
   - Added `test_mobile_dynamic_dropdown_portrait` and `test_navigation_mode_switching_by_viewport` in `tests/test_playwright_responsive.py`.
   - Full suite now runs 51 automated tests covering responsive viewports, contrast modes, dark mode, accessibility, and static build integrity.
