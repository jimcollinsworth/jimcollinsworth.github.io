# Release v0.7.1 — Big Display Typography Scaling & Full-Screen App Header Unification

> Scaled site branding on wide displays (1360px+), unified full-screen application header navigation and controls, and verified uncropped container alignment.

---

### Overview

`v0.7.1` refines high-resolution typography and standardizes the full-screen application experience across all interactive tools, including Pipeline Tools.

---

### Key Changes

1. **Big Display Typography Scaling**:
   - Site title scaled to `1.95rem` and tagline to `1.45rem` on wide displays (`@media (min-width: 1360px)`).
   - Base desktop site title set to `1.55rem` and tagline to `1.25rem`.
   - Large-text mode tagline scaled to `1.65rem`.

2. **Full-Screen App Header Unification**:
   - Standardized top header bar across Photo Viewer, Keyword Explorer, and Pipeline Tools.
   - Added theme toggle and browser full-screen request buttons to `apps/pipeline-tools/index.html`.
   - Unified `? Back to Apps` link styling.

3. **Testing & Validation**:
   - 51 passing automated tests in `pytest -v`.
   - Zero client-side JavaScript on published content pages.
