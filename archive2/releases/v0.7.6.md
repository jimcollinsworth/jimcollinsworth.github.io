# Release v0.7.6 — Condensed Ideas Stream & Provenance Filtering

> Introduced the /ideas.html stream for unpolished concepts, prompts, and seedlings using type: IDEA, with an ultra-dense, metadata-free title list, distinct provenance icons, feed isolation from posts and homepage, and smart back navigation.

---

### Key Changes

1. **Condensed Ideas Stream (`/ideas.html`)**:
   - Created standalone page `content/pages/ideas.md` rendered via dedicated template `theme/templates/ideas.html`.
   - Ultra-condensed, high-density listing displaying strictly `[Provenance Icon] + Title Link` with dotted row borders and no metadata clutter (no dates, tags, or summary blurbs).

2. **Feed Isolation**:
   - Filtered out `type: IDEA` from homepage featured post and recent stream in `theme/templates/index.html`.
   - Filtered out `type: IDEA` from `posts.html` archive list in `theme/templates/archives.html`.
   - Added subtle link in `posts.html` intro: *"For unpolished concepts and future seedlings, see Ideas &rarr;"*.

3. **Smart Navigation**:
   - Updated `theme/templates/article.html` so back arrow dynamically returns to `/ideas.html` when viewing an `IDEA` post type, preserving browsing context.
