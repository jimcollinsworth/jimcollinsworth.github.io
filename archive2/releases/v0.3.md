# Release v0.3 — Pelican SSG Integration & Automated Testing

> Modernized build pipeline with Pelican Static Site Generator, custom Jinja2 theme, Obsidian frontmatter bridge, and automated E2E test suite.

---

### Overview

`v0.3` transitioned site compilation to the Python-based Pelican static site generator. It introduced drop-folder content management compatible with Obsidian notes, implemented an automated test suite, and established continuous integration via GitHub Actions.

---

### Key Features & Changes

- **Pelican Static Site Generator Integration**: Automated compilation from Markdown source into static HTML5 using Python and `uv`.
- **Obsidian Frontmatter Reader**: Custom `ObsidianMarkdownReader` in `pelicanconf.py` seamlessly parsing standard YAML frontmatter headers (`---`).
- **Structured Content Drop Directories**:
  - `content/posts/` &mdash; Long-form dated articles and lane posts.
  - `content/pages/` &mdash; Standalone timeless pages.
  - `content/images/` &mdash; Manually curated image assets.
  - `content/extra/` &mdash; Root metadata assets (`favicon.svg`, `.nojekyll`).
- **Title Deduplication & Clean Lane Styling**: Removed redundant `<h1>` headers on standalone pages and replaced pill/badge buttons with simple, understated text links.
- **Automated E2E Test Suite (`tests/test_pelican_e2e.py`)**: 8 automated tests validating build generation, link/image integrity, and zero-JS compliance on every commit.
- **GitHub Actions CI/CD**: Workflow automating `pytest` audits, Pelican builds, and GitHub Pages deployments on push.
