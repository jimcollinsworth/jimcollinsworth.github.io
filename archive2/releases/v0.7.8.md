# Release v0.7.8 — Pure Markdown Content Migration, Automatic Link Resolution & Dedicated Blueprints

**Release Date:** September 14, 2026  
**Commit:** Milestone 44  
**Tag:** `v0.7.8`

---

### Overview

Release `v0.7.8` implements pure Markdown authoring standards across the entire content directory (`content/pages/` and `content/posts/`), removing all raw HTML wrappers, inline SVG icons, and hardcoded layout blocks. Pelican's custom `ObsidianMarkdownReader` was upgraded to automatically resolve Markdown `.md` links and Obsidian `[[wikilinks]]` into valid Pelican intra-site references, while automatically wrapping standalone images into responsive `<figure>` and `<figcaption>` elements.

---

### Key Changes

1. **Automatic Intra-Site Link Resolution (`pelicanconf.py`)**:
   - Upgraded `ObsidianMarkdownReader` with recursive content map discovery.
   - Converts standard Markdown links (e.g. `[Development Prompts](prompt-history.md)`) and Obsidian wikilinks (e.g. `[[target|label]]`) into Pelican `{filename}` directives so Pelican calculates exact relative HTML URLs.
   - Maps `posts.md` and `posts` references to relative `posts.html`.

2. **Automated Figure Wrapping (`pelicanconf.py`)**:
   - Automatically parses Markdown images (`![alt](src)`) into semantic `<figure><a class="photo-link"><img ...></a><figcaption>alt</figcaption></figure>` markup with automatic relative image path normalization between root pages and `posts/` subdirectories.

3. **Dedicated Jinja2 Blueprints (`theme/templates/`)**:
   - `about-this-site.html`: Renders Markdown content and appends the structured DevOps & Infrastructure Dashboard.
   - `apps.html`: Renders Markdown introduction and tabular data overview alongside application launcher cards.
   - `photos.html`: Implements `.photo-gallery-page` 2-column grid layout for pure Markdown image lists.
   - `links.html`: Hosts the curated links and reading list 2-column layout.

4. **Pure Markdown Content Sources (`content/`)**:
   - Purged `<div class="page-intro">`, raw card containers, and inline SVG icons across `content/pages/` and `content/posts/`.
   - Lead paragraph styling applied automatically via `.page-body > p:first-of-type` and `.post-content > p:first-of-type` in `style.css`.

5. **Test Suite Expansion (`tests/test_pelican_e2e.py`)**:
   - Added `test_pure_markdown_content_sources()`: Validates zero raw HTML tags across author-facing content files.
   - Added `test_markdown_link_and_figure_resolution()`: Confirms intra-site link compilation and figure transformation.
   - Test suite expanded to 54 passing tests.
