# Release v0.7.11 — Margin Alignment, Edge-to-Edge Photo Bleed, Apps Table Removal, AI Props & About Site Restructuring

**Release Date:** September 15, 2026  
**Commit:** Milestone 48  
**Tag:** `v0.7.11`

---

### Overview

Release `v0.7.11` corrects left/right margin alignment across viewports, scopes zero-margin edge-to-edge photo bleed strictly to the photo stream, removes the obsolete static data architecture table from the Apps hub, adds automated responsive horizontal scrollbars for wide data tables, and streamlines the About This Site page with prominent AI attribution and the 8-stanza AI haiku summary positioned directly after the introductory overview.

---

### Key Changes

1. **Margin Alignment & Scoped Photo Bleed (	heme/static/css/style.css, 	heme/templates/photos.html)**:
   - Removed .photo-gallery-page from the negative margin selector, restoring standard container margins to .photos-header (title, summary, Google Photos badge).
   - Scoped zero-margin edge-to-edge bleed exclusively to .photo-stream on mobile and tablet viewports.
   - Padded .photo-stream figcaption to align caption prose with standard page reading margins.

2. **Apps Hub Table Removal (content/pages/apps.md)**:
   - Removed the obsolete `Static Data & Deployment Architecture` section and markdown table from `content/pages/apps.md`.
   - Cleaned the Apps hub to feature concise introductory copy leading directly into the interactive application cards.

3. **Responsive Table Horizontal Scrollbars (pelicanconf.py, 	heme/static/css/style.css)**:
   - Added `_wrap_tables` to `ObsidianMarkdownReader` to automatically wrap rendered `<table>...</table>` elements inside `<div class="table-container">`.
   - Configured `overflow-x: auto; -webkit-overflow-scrolling: touch;` on `.table-container` and fallback styling on standalone tables.

4. **About This Site Restructuring & AI Attribution (content/pages/about-this-site.md, 	heme/templates/about-this-site.html)**:
   - Updated lead introductory paragraph to credit AI pair programming under Jim's direction for managing static builds, responsive CSS, and test automation.
   - Removed verbose Antigravity programming, workflow diagrams, and licensing sections.
   - Positioned the 8-stanza `Summary (written by AI)` haiku grid as the second element on the page immediately following the lead intro paragraph.
