# Release v0.7.4 — Custom Domain DNS Mapping & CNAME Configuration

> Diagnosed mobile resolution frameset anomaly on jimcollinsworth.com, configured GoDaddy apex A records to GitHub Pages, added CNAME file to Pelican pipeline, and established live custom domain routing.

---

### Key Changes

1. **Custom Domain Diagnosis**:
   - Identified GoDaddy domain forwarding with masking serving an HTML 4 `<frameset>` without `<meta name="viewport">`, causing mobile browsers to default to 980px desktop view.

2. **DNS & CNAME Configuration**:
   - Updated GoDaddy DNS: 4 apex `A` records to GitHub Pages IPs (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) and `www` `CNAME` pointing to `jimcollinsworth.github.io`.
   - Added `content/extra/CNAME` mapped in `pelicanconf.py` `EXTRA_PATH_METADATA` so Pelican produces `output/CNAME` on every build.
   - Bound custom domain in GitHub Pages with enforced HTTPS.

3. **Automated Verification**:
   - Added automated test in `tests/test_pelican_e2e.py` validating `output/CNAME` existence and content.
