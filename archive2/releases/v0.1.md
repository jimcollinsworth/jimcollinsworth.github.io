# Release v0.1 — Clean Foundation & Governance

> Initial release establishing the pure static web architecture, archiving legacy Nikola compiler assets, and codifying agent governance rules.

---

### Overview

`v0.1` represents the foundational reset of `jimcollinsworth.github.io`. The previous Nikola/Python compiler pipeline was cleanly retired into an archive directory in favor of a fast, distraction-free, zero-JavaScript architecture with strict separation between technical maintenance and human content ownership.

---

### Key Features & Additions

- **Zero-JavaScript Foundation**: Standardized on 100% pure HTML5 and modern CSS with zero `<script>` tags, zero tracking cookies, and zero runtime dependencies.
- **The 12 Exploration Lanes**: Established the primary taxonomy representing Jim's retirement pursuits: Music Making, Software, Life Sciences, Engineering, Photography, Making, Law, Art, Politics, Data, Exercise, and Anatomy.
- **Legacy Asset Archival**: Safely migrated legacy build outputs, drafts, notes, and photos into `archive/`.
- **Agent Governance System**: Formulated `.agents/agent_rules.md` enforcing:
  1. The **Mandatory 3-Document Rule** (`README.md`, `PLANNING.md`, `JOURNAL.md`).
  2. **Strict Content Ownership** (Agent strictly restricted to infrastructure/management; Jim authors all content).
  3. **Standard CLI Standards** for reproducible manual execution.
