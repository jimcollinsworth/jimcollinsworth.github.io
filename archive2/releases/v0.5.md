# Release v0.5 — Magazine Grid Layout, Orientation Modes & Progressive Density

> Modern responsive layout overhaul featuring 2-column magazine grid, orientation adaptation, and pure CSS progressive information density.

---

### Overview

`v0.5` significantly expanded the visual and spatial hierarchy on large screens. It eliminated excessive empty gutters on desktop/laptop displays, implemented a 2-column magazine grid, introduced orientation-aware layouts, and established progressive density rules without requiring JavaScript.

---

### Key Features & Changes

- **Fluid Container Scaling**: Expanded maximum layout width from `720px` to `1080px` on desktop/laptops and `1380px` on ultra-wide screens (`>= 1360px`).
- **2-Column Magazine Grid (`.desktop-two-col`)**: Structured home page into a balanced two-column grid:
  - *Primary Column (Left)*: Featured lead article + recent book reads.
  - *Secondary Column (Right)*: Chronological posts feed + photo spotlight.
- **Orientation-Driven Layouts**:
  - *Portrait Mode*: Single-column focused reading stream.
  - *Landscape Mode*: Side-by-side split layout utilizing screen width.
- **Pure CSS Progressive Density**:
  - Desktop/Laptop: Displays full excerpts and complete metadata (`.post-detail`).
  - Mobile (`< 640px`): Collapses secondary metadata into concise single-line teasers (`.post-teaser`).
- **Body Measure Constraint**: Constrained body prose to `max-width: 76ch` to maintain comfortable line lengths across wide screens.
- **Multi-Viewport Visual Verification**: Validated layouts across mobile portrait, tablet portrait, tablet landscape, laptop, and ultra-wide viewports.
